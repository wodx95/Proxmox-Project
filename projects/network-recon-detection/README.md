# Network Reconnaissance and Detection

This project demonstrates the detection of network reconnaissance activity within my Proxmox lab using Nmap, UFW firewall logging and Splunk.

## Scenario

A Kali Linux VM was used to perform network reconnaissance against an Ubuntu endpoint. The activity was then investigated using logs collected by Splunk.

The initial authentication logs provided evidence of interaction with the SSH service, but did not provide visibility of the complete port scan. To improve network visibility, UFW firewall logging was enabled on the Ubuntu endpoint.

## Detection

After enabling UFW logging, blocked connection attempts generated by the Nmap scan became visible in Splunk.

I created a behavioural Splunk detection to identify source hosts attempting to connect to five or more unique TCP destination ports within a one-minute window.

The detection was then configured as a scheduled Splunk alert. After repeating the Nmap scan, the alert triggered successfully.

## Detection Search

```spl
index=main host="ubuntu-client" "UFW BLOCK" "PROTO=TCP"
| rex "SRC=(?<src_ip>\d+\.\d+\.\d+\.\d+)"
| rex "DST=(?<dest_ip>\d+\.\d+\.\d+\.\d+)"
| rex "DPT=(?<dest_port>\d+)"
| bin _time span=1m
| stats count AS attempts dc(dest_port) AS unique_ports values(dest_port) AS ports by _time src_ip dest_ip
| where unique_ports >= 5
| sort - _time
```
